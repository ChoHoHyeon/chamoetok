# 참외톡톡 — 플레이 스토어 등록 정보 초안

## 앱 이름 (30자 이내)
참외톡톡 – 과일 퍼즐

## 짧은 설명 (80자 이내)
같은 과일 4개를 붙이면 톡! 연쇄로 상대에게 바위를 보내는 귀여운 낙하 퍼즐

## 자세한 설명 (4000자 이내)
🍈 참외톡톡은 말랑말랑 귀여운 과일 캐릭터들이 등장하는 낙하형 퍼즐 게임입니다.

위에서 떨어지는 참외·토마토·수박·연꽃 두 개를 좌우로 옮기고 회전해서 쌓으세요.
같은 과일이 상하좌우로 4개 이상 붙으면 톡! 하고 터집니다.

✨ 핵심은 연쇄!
터진 자리로 위에 있던 것이 무너져 내려 또 터지면 연쇄가 이어집니다.
2연쇄, 3연쇄, 5연쇄… 연쇄가 길수록 점수가 폭발하고 화면이 흔들립니다.

🪨 CPU 대전
연쇄를 터뜨리면 상대 판에 바위가 떨어집니다. 바위는 옆의 과일이 터질 때 같이 사라져요.
쉬움·보통·어려움 3단계 CPU와 대결하세요. 3번째 칸 맨 위까지 쌓이면 패배!

🎮 특징
• 말랑말랑 반응하는 귀여운 과일 캐릭터 (착지하면 찌그러지고, 3개 붙으면 눈이 반짝!)
• 혼자하기(무한 모드) + CPU 대전 3단계
• 1× / 2× / 4× 속도 조절
• 회원가입 없음, 광고 없음, 인터넷 없이 플레이
• 키보드·터치 모두 지원

등장 캐릭터: 참외, 토마토, 수박, 연꽃, 가지, 그리고 심술궂은 바위

## 등록 절차 요약
1. Google Play Console 개발자 계정 생성 (25달러, 1회) → 신원 확인
2. 앱 만들기 → 스토어 등록정보 입력(위 내용) → 콘텐츠 등급 설문 → 데이터 보안 섹션("데이터 수집 안 함")
3. 비공개 테스트 트랙에 AAB 업로드 → 테스터 12명 이상 14일간 테스트 (신규 개인 계정 의무)
4. 프로덕션 출시 신청 → 검토(보통 며칠)
